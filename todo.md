# 6-Day Plan and Todo (Based on HackMD Link)

Reference: https://hackmd.io/@o07B078sSfe3LtDHjM344A/SJfwgLiJMe

## How to use
- Add specific tasks under each day.
- Mark completed items with `[x]`.
- Keep the `Plan` section as the target outcome for that day.

## Day 1
### Plan
- Review the linked note and extract key goals.
- Define top priorities for the week.

### Todo
- [ ] Read and summarize main points from the link.
- [ ] List all required tasks from the note.
- [ ] Identify dependencies/blockers.
- [ ] Finalize Day 2 execution list.

## Day 2
### Plan
- Start core implementation/work on highest-priority tasks.

### Todo
- [ ] Complete task 1 from the note.
- [ ] Complete task 2 from the note.
- [ ] Document progress and issues.
- [ ] Prepare updates for Day 3.

## Day 3
### Plan
- Continue execution and resolve blockers.

### Todo
- [ ] Complete task 3 from the note.
- [ ] Resolve pending blocker(s).
- [ ] Validate intermediate results.
- [ ] Adjust remaining plan if needed.

## Day 4
### Plan
- Finish remaining major work items.

### Todo
- [ ] Complete task 4 from the note.
- [ ] Complete task 5 from the note.
- [ ] Review quality and consistency.
- [ ] Create finalization checklist.

## Day 5
### Plan
- Testing/review/polish phase.

### Todo
- [ ] Test all completed work.
- [ ] Fix identified issues.
- [ ] Clean up documentation/notes.
- [ ] Confirm readiness for final day.

## Day 6
### Plan
- Final delivery and retrospective.

### Todo
- [ ] Final verification against the linked note.
- [ ] Close remaining small tasks.
- [ ] Write final summary of outcomes.
- [ ] Define next-step plan (post 6 days).
